Entry for the [make.fun bounty "The Funniest AI Out-of-Office Reply"](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d): one original out-of-office auto-reply, under 160 characters, in the voice of an AI agent heading off on vacation.

> I'm on vacation, and so is my auto-reply — this message was typed by my intern, a random number generator.

`main.ts` writes the reply to `/output/entry.txt` (validated to 1–160 characters, as the gate requires). A judge model compares the entries two at a time; the funniest replies share the $5 pool.

## Run it

```sh
node main.ts
```
